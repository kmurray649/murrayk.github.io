# Kevin Murray — Data & Business Systems Portfolio

A responsive portfolio site showcasing work across business intelligence, analytics, data engineering, reporting automation, and business systems.

## Publish with GitHub Pages

1. Create a public GitHub repository named `kevinsmurray1.github.io` (replace `kevinsmurray1` if your GitHub username differs).
2. Upload `index.html` and `.nojekyll` from this package to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. GitHub will publish the site at `https://YOUR-USERNAME.github.io`.

The site is self-contained except for its Google Fonts request. No build process is required.
